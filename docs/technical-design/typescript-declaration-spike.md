# TypeScript declaration parser spike

**Status:** Isolated local WP2 precursor; not a production adapter, released pack, or WP2 acceptance. The WP1 contract freeze remains open.

`packages/extractor-spike` uses the pinned TypeScript compiler's public syntactic API on caller-supplied text. It does not read a repository, resolve an import, run a build script, execute source code, load a semantic index or connect to an enterprise source. It returns only top-level class/interface/function names, class method names and declared parameter/return-type text, with one-based source lines. Overloads remain separate declarations; their signature strings are not type-resolved identities.

The prototype withholds all declarations when syntax diagnostics exist and reports unsupported anonymous or computed names. `extractTypeScriptCapture` accepts caller-supplied capture/file metadata and one byte buffer; it checks manifest consistency, path shape, size, raw SHA-256/length and UTF-8, then emits deterministic `engineering.symbol` records, file-range locators, diagnostics and explicitly **partial** file-unit coverage. It returns no records for a syntax error. Source classification is not downgraded. `assembleTypeScriptCandidate` closes a declared list of up to 100 supplied files, sorts them deterministically, aggregates file-unit coverage, validates the combined record/evidence set and emits canonical record JSONL plus a candidate digest. Missing, extra, duplicate or changed supplied bytes fail the whole candidate. This pure assembler does not scan or open files and cannot attest the origin or completeness of a caller's declared source manifest, approve publication or activate a pack. IDs are prototype-stable only under the current adapter identity rule. No byte spans, semantic resolution or trusted adapter provenance are emitted.

`readBoundLocalCapture` is a Linux-only, single-operator bridge from an explicitly chosen absolute root and complete declared file list to those supplied bytes. It traverses each path beneath an open directory descriptor using `/proc/self/fd` and `O_NOFOLLOW`, refuses symlinks, hard-linked/non-regular files, hidden/blocked directories and sensitive-looking filenames, missing/oversized files and changed digests, and never discovers sibling files. Per-file reads are bounded to 1 MiB; the declared set is bounded to 100 files and 16 MiB. `assembleLocalTypeScriptCandidate` composes this read with the pure assembler. This is **not** a source-control revision attestation, a secret scanner, a multi-user authorization boundary, a publication grant, or a defense against a hostile same-user process changing the root. Do not use a network or cross-user serving path around it.

`searchLocalSymbols` is a first offline exact/lexical pointer baseline over this candidate. It ranks short/qualified symbol names, signatures and paths, returns a bounded file-range locator with candidate digest, origin, review state, classification and partial-coverage warning, and makes no claim about runtime behavior or business truth. It does not apply user-specific authorization, traverse relationships, compare typed retrieval, or run an agent workflow. Do not expose it as a shared search service. The provisional `engineering.symbol` payload now permits a qualified name so an overload or class member can be found without guessing from a hash ID.

Imports, class fields, constructors, accessors, interface methods, nested declarations, TSX and dynamic router registrations are outside this narrow output family; their absence is **not** evidence that they do not exist. File-unit coverage does not measure declaration-family recall. A real adapter must establish an eligible-unit denominator and emit coverage/unsupported diagnostics before any completeness claim.

Fourteen synthetic tests exercise overloads, a computed method name, an import that is never executed, anonymous declaration, syntax failure, deterministic source-bound output, stale bytes, metadata mismatch, invalid UTF-8, byte limits, multi-file ordering, all-or-nothing declared-file closure, local path/symlink/hard-link denials, qualified lookup and bounded lexical pointers. No private evaluation repository content or source-derived fixture is included. Integrate with trusted captures and a frozen WP1 contract only after the evidence boundaries have passed review.
